# Sistema de Funcionários

Mini sistema desenvolvido para praticar Programação Orientada a Objetos com JavaScript.

## Funcionalidades

* Cadastro e listagem de funcionários;
* Diferentes cargos;
* Validação de salário;
* Tratamento de erros;
* Navegação dinâmica.

## Tecnologias

* HTML;
* CSS;
* Bootstrap;
* JavaScript.

## Conceitos praticados

Classes, herança, encapsulamento, polimorfismo, arrays, DOM e eventos.

## Como executar

Abra o arquivo `index.html` no navegador ou utilize o Live Server.
